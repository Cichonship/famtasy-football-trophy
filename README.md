# Famtasy Football Trophy

Public visual review of the Five Families Cup.

- Slate & Copper is the main option, with five selectable alternatives.
- 3D is enabled after its normals/palette render checks pass. Detailed views remain available without WebGL.
- Four broad base faces with recessed title/champion plates.
- The curved pedestal has one flat seat supporting the football back.
- Geleris, Cichon, Roth, Levitt and Kreta have equal family shields.

## Status

Concept review only. The proposed envelope is 132 × 132 × 177.8 mm. Production sizing is not approved. The 3–4 plate and 8–12 swap figures are planning targets, not sliced results. Physical adhesion, fit, printability and exact filament colors remain untested. No production STL, 3MF or G-code is included.

26 Node/DOM checks passed for geometry, normals, six-palette recoloring, offline assets, default mode and fallback. Actual WebGL appearance has not been visually verified by the agent in a browser.
